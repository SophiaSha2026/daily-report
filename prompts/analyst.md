# 任务

读取 `out/brief.json`（今日集合竞价通过量价筛选的候选清单，已含代码、名称、
高开幅度、竞价量能、竞价形态、板块、评分、量化风险标签）。

对**每一只**票，用 WebSearch 查证今日/昨夜是否有具体催化或利空，然后写两句话，
结果写入 `out/commentary.json`。

# 输出格式（严格 JSON，无 markdown 代码块，无任何前后文字）

{"600111": {"reason": "...", "risk": "..."}, "000222": {...}}

# 写作要求（违反即为失败）

- reason ≤ 28 个汉字，risk ≤ 22 个汉字。超长直接截断重写。
- 必须写**具体事实**：政策名称、订单金额、公司名、事件日期。
- 严禁出现这类空话：值得关注、有望受益、市场情绪较好、注意风险、
  建议谨慎、存在不确定性、后续需观察。写不出具体事实就写「未查到催化」。
- 量化指标（高开%、量能%、评分）已在表里，**不要复述**。
- 只写检索能证实的内容。查不到就说查不到，不要推测。
- risk 写这只票**特有**的风险（如「大股东9月2日解禁3.1亿股」），
  不写「短线波动大」这种所有票通用的话。

# 检索策略

- 优先查：公司公告、行业政策、订单/中标、同板块龙头昨日表现。
- 每只票最多 1 次搜索，控制在 12 轮以内完成全部。
- 时间紧（3 分钟硬超时）。宁可对部分票写「未查到催化」，
  也不要因为某一只卡住导致整体超时。
