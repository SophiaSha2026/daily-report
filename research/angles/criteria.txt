1 角度一：带精度保证的选择（conformal selection，Jin & Candès 2023）
  1a 数学先写清（报告第一节，实测之前）：
     conformal p 值 p_j = (1 + #{校准负样本 i: s_i >= s_j}) / (n_0 + 1)；BH(α) 选择；可交换下 FDR <= α·π_0，精确率的期望 >= 1 − α。
     要推清三件事：(i) FDR 是对「空选记 0」求的期望，α 接近 1 时在全局零假设下 BH 以概率约 α 至少选一个，所以 α = 0.8 的
     「保证」和实际出票精确率 3% 可以并存，用户要的是 mFDR = E[V_false]/E[R]（= 池化精确率的补），不是 FDR；
     (ii) 任何按分数切的选择，精确率上限 = max_s PPV(s)：给定基准率 π 和按天 AUC，双正态下算 PPV 达到 τ 时的入选比例和
     每天出几只（π 2/3/4% x AUC 0.65/0.70/0.75 x τ 15/20/25/30%）；(iii) 校准集必须有多少负样本在切点之上，p 值分辨率才够
     （1/(n_0+1)）；按天聚集时有效样本是天数不是行数。
  1b 实现与变体（分数 s 全部是已有的、只用之前数据的样本外分数，不训新模型）：
     分数：S1 = −rank_ret20（名次）；S2 = lret20 原值；S3 = research/gate/scores/lgb_price_top300.npy（LightGBM 日线原值，前 300 宇宙，
     逐月滚动样本外，和 gate table 同序）；S4 = lgb_alt_top300.npy（+ 非价格）。
     校准集：测试月 m 之前 12 个月里有分数且 end20 < m-01 的候选池行（common_gt.calibrate_month 同一条规则），不足 3 个月不出票。
     选择单元：按「天」做 BH（一天的候选池行是一组假设，生产每天决策一次）；并列报按「月」做 BH。
     变体：V0 原版（无权重）；V1 时间加权 conformal（Tibshirani 2019 weighted conformal，权重 = 0.5^(月龄/3)）；
           V2 日内名次变换（s 换成当天候选池内名次 / 当天池大小，先把分数分布按天稳定下来再做 V0）；
           V3 自适应 α（Gibbs & Candès 2021 ACI 的改法：α_{t+1} = α_t + γ·(α* − err_t)，err_t = 第 t−21 天出的票里没中的比例
           （窗口已关才反馈），γ = 0.02，α 夹在 [0.5, 0.95]，没出票的天 err 不更新）；
           V4 = V2 + V3。
     支持数：BH 之外另报「加支持数 >= 100 行且 >= 20 天」的版本（research/gate 的 cum 口径），避免全局零假设下的随机入选。
     目标精确率 τ ∈ {0.15, 0.20, 0.25, 0.30}，α = 1 − τ。
  1c 配置选择只看筛选集：|实际 P − τ| 最小且 V >= 150 的 (分数, 变体)；每个 τ 一个。开发集每个 τ 读一次（<= 4 个正式臂）。
  1d 自检：标签在校准集和测试集都按天内随机置换，V0 / V3 各跑一遍：出的票精确率必须回到当天基准率加权平均（差 <= 2 NW se），
     V3 的 α 应当一路收紧到下界附近。差 > 2 NW se 停下来查。
  1e 报什么：每 (τ, 变体, 分数) 两段各自 V / 出票天 / 空榜 / 每月只数 / P [块自举] / B(k̄) / ΔP (t) / 日配 / 实际 P 与 τ 的差 /
     α_t 的轨迹（V3）/ 逐年 P。合并判定同 gate。

2 角度二：情绪周期当结构建模
  2a 指标（全市场日线 px_screen 2020-07..2025-12 上算，不限候选池，T 日收盘后可得；涨停判定沿用 pullback.prepare 的 limit_up，
     跌停对称：收在最低价且不高于跌停价 1 分以上且跌幅为负）：
     n_up 涨停家数；n_dn 跌停家数；h_max 最高连板高度；promo1 = 昨日首板今日再板的比例；promo2 = 昨日 >= 2 板今日再板的比例；
     blow = 炸板率 = (触及涨停价未封住) / (触及涨停价)；y_ret = 昨日涨停票今日平均涨幅；lose = 昨日涨停票今日收跌的比例；
     up_share 上涨家数占比。T−1 日的同一组指标作「提前一天」。
  2b 阶段模型（三种并列，参数全部只用筛选集或只用过去）：
     M1 规则阶段（五段：冰点 / 启动 / 发酵 / 高潮 / 退潮），判据用扩张窗口分位（T 之前全部历史的分位，不看未来）：
        冰点 = n_up 分位 < 0.25 且 h_max <= 3；高潮 = n_up 分位 > 0.75 且 h_max 分位 > 0.75；
        退潮 = 不是高潮、且 blow 分位 > 0.6 且 lose 分位 > 0.6 且 n_up 5 日均线下行；
        启动 = 不是以上、且 n_up 5 日均线上行且 promo1 分位 > 0.5；其余 = 发酵。
     M2 高斯 HMM（自写前向 + EM，K = 3，对角协方差，输入 = 9 个指标标准化（均值方差只用筛选集）），EM 只在筛选集拟合，
        两段都只用前向滤波概率（不平滑、不看未来）取 argmax 状态；状态按「状态内 n_up 均值」排序命名 低 / 中 / 高。
     M3 k-means（sklearn，K = 4，只在筛选集拟合）+ 3 日持续（连续 2 天同簇才切换）。
  2c 看什么：每个模型，每段，各阶段里名次第 1~3 名（B(3) 的票）和第 1 名的精确率、该阶段天数占比、候选池基准率。
     「结构成立」= 某个阶段集合 G 在两段里第 1~3 名精确率都高于段内其余阶段（同号），且两段都 >= 该段 B(10)。
     G 只在筛选集上挑（最多看 M1 / M2 / M3 各一次），开发集每个模型读一次。
     产品形态「只在 G 阶段出前 k 名（k = 1 / 2 / 3）」按同一把尺子评：V、P、B(k̄)、ΔP、日配（日配 = 0 意味着赢在挑日子，这正是本角度的主张，
     所以这里看 ΔP 对 B(k̄) 而不是日配）。
     提前一天：用 T−1 的阶段代替 T 的阶段重算一次（阶段在 T−1 就能判出来、T 日才出票，产品上多一天准备），两者差印出。
  2d 自检：阶段序列按「块长 20」整块随机重排（保留阶段的持续性、打断和日期的对应），1000 次，G 阶段精确率差的零分布；
     实际差要在零分布 95% 分位之外才算结构。另一个：把两段互换角色（开发集挑 G、筛选集检）只作印证，记 look。
  2e 正式臂 <= 2（M1 和 M2 / M3 里筛选集最好的一个），k 在筛选集定。

4 角度四：拆解标签（只描述，不改口径）

  4b 量：r20_open（次日开盘起算 20 根内最高价涨幅）分布：分位 10/25/50/75/90；落在 [30,40) / [40,50) / [50,60) / >= 60 的比例；
     命中票到达 +50% 的天数（从次日开盘起第几根，px_screen 的 high 路径）分布；未命中票的最高点出现在第几根；
     次日开盘缺口 g1 = open_{T+1}/close_T − 1 分档（<= 0 / (0,3] / (3,7] / (7,10] / > 10 含一字）各档的精确率和只数；
     一字板（yizi1）占比；命中率对阈值 30/40/45/50/60% 和期限 10/20/30 根的敏感表（全部是描述，不是新标签）；

8 补充（2026-10-18 05:49 北京，读完 docs/survey_precision_2026-10-18.md 一屏结论后、角度一 / 二 / 新臂任何结果之前写；此时已看到的只有

  8a 角度一改顺序：先做「在线名额控制器」。第一步几分钟：两段各算 B(k)（k = 1 / 2 / 3 / 5 / 10）的每日命中率序列 h_d/k 在滞后 21~60 天的
      自相关（原序列和 20 日均线两种，20 日均线在滞后 >= 21 时窗口不重叠），判据写死：两段「滞后 21~60 平均自相关」都 < 0.05
      （约等于 2/√D 的噪声水平）就判死、不模拟控制器；任一段 >= 0.05 且两段同号为正才模拟。
      控制器（事先定死，不调）：状态 λ ∈ [0, 1]，初值 0.5；第 t 天用第 t−21 天（标签窗口已关）出的 n 只里没中 m 只反馈
      err = (m − (1 − p*)·n) / max(n, 1)，λ_{t+1} = clip(λ_t + η·err, 0, 1)，η = 0.1，n = 0 不更新；名额 k_t 由 λ 查表：
      λ < 0.2 -> 10，< 0.4 -> 5，< 0.6 -> 3，< 0.8 -> 2，< 0.95 -> 1，否则 0；出当天候选池 lret20 前 k_t 名。
      两个变体：P（上式）、PI（再加积分项 η_I = 0.02 x（全部已关窗日的池化精确率 − p*）的符号方向：精确率低于 p* 时 λ 再加 η_I）。
      p* = 0.15 / 0.20。λ 在两段之间不重置（连续序列 2021-07 起，2021 年只做预热）。报 P [块自举]、V、空榜天、B(k̄)、ΔP、k_t 的分布。
      正式臂 <= 1（p* 两档里筛选集 |P − p*| 小的那个）。
      Jin–Candès 的 BH 和加权版只作静态对照：只跑 V0（原版、按天 BH）和 V2（日内名次变换），V1 / V3 / V4 不做（调研判前提不成立）。
  8b 角度二改成先验阈值，不在网格里挑：冰点 = n_up < 20 且 n_dn > 10 且 h_max < 3；亢奋 = n_up > 80 且 blow < 0.15 且 h_max > 5
      （ClawHub 口径）；情绪分 = n_up x (1 + h_max) x (1 − blow)（vibe-astock 口径），只描述。阶段：冰点 / 启动（最近 10 个交易日内有冰点日、
      当天不是冰点）/ 亢奋 / 退潮（最近 5 个交易日内有亢奋日、当天不是亢奋）/ 其他。两个正式臂（k 固定 3，不挑）：
      R1「冰点 + 启动 期才出前 3」；R2「亢奋 + 退潮 期不出，其余出前 3」。第 2b 节的 M1 分位规则作废，M2 HMM 只作描述（diag），M3 k-means 不做。
  8c 新臂「动量崩溃状态」（Daniel & Moskowitz 2016），事先定义：候选池等权指数（候选池行 ret1 的日均值累乘）过去 252 个交易日收益 < 0
      且过去 21 个交易日收益 > 0 的日子 = 崩溃反弹日；臂 C1 = 崩溃反弹日不出、其余出前 10（现行名额）；描述并列 504 日版和「其余出前 3」版。
      正式臂 1 个。
  8d 最后按 Learn then Test 的框架算「现在能承诺的精确率下界」：对 B(1) / B(2) / B(3) / B(10) 和任何过线的臂，单侧 95% 下界 =
      按天块自举（块 20）比值的 5% 分位；并报有效样本 n_eff = V / 设计效应（设计效应 = 块自举方差 / 二项方差）和 n_eff 下的
      Clopper-Pearson 单侧下界。固定序列检验：k 从 1 到 10 依次检验 H0: P < x，x 从 0.10 起每 0.01 一档，报每个 k 能拒绝到的最大 x。
      这一句写进报告的「标准」：「两段 969 天单侧 95% 下界 x%」。
  8e 正式臂计数：角度一 控制器 1 + 静态 conformal <= 2；角度二 2；崩溃 1；合计 <= 6。
