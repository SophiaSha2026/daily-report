## 选臂：0 个

预登记（15:02，看结果前）：合格 = 按天差 > 0 且 NW t ≥ 1.0 且滚动三月 ≥ −5pp；按 NW t 排序，平局按 lr20 t；rel / soft 各最多一个；取前 2；入选加种子 9。合格 0 个。screen_draft.json 为 `{}`。

若只按 evalkit 规则 7（同号）放宽，同号的是 eqd / y_rel2 / y_softh / y_softz（y_rel4、y_rel4_eqd 异号不能登记）。子代理不建议：这是事后放宽；筛选集 se 0.47pp 已能看出 +1pp 以上的效应而没看出，开发集 MDE +3.4pp，这些臂过不了线，登记只会抬高族门槛。

**设计上的局限**：y_rel / eqd 的动机是 2024-09（一个月占开发集正样本 34%）。筛选集没有这样的月份，正常月份里相对标签和 50% 阈值几乎是同一批票，所以筛选集只能回答「相对标签在普通行情下有没有害」（没害，也没益），回答不了「它能不能化解 924」；而在含 924 的开发集上测又会被那一个月主导。用 924 做动机、再用含 924 的开发集做判定，本身不是可靠的试验设计。

## 六个判断的理由

1. **eqd 嵌在按月等权里**：w = 1/(当天行数 × 当月天数)，每月权重和不变，只改月内分配，隔离「月内按天」这一层。筛选集最大日 / 中位日正样本 287 / 81 = 3.5 倍，没有 924 那种悬殊，eqd 在这里可改的不多（Jaccard 0.61，se 0.28pp）。
2. **evw 归一**：正样本行 1/段长，再把每月正样本权重和拉回该月正样本行数，负样本 1，最后乘按月等权；避免类别平衡从 1:12 变成 1:170。归一后仍 −2.44pp，说明长段本身就是信号。
3. **y_soft 采样**：按 u 分层，u > 0.8 全留，u ≤ 0.8 随机补到该月 13 × 当月 y_up 正样本数，冷行至少热行一半；两个软标签同行集合。每月平均 72.4 万行对 base 57.1 万。不用 stratified_sample(y_up)：按结果采样会让回归学到被采样畸变的条件期望。
4. **诊断**（2023-03，23 天）：Spearman(p, y_open) base 0.1310、y_rel4 0.1325、y_softh 0.1336、y_softz 0.1339，软标签不低于 y_rel4，进主循环。
5. **预登记**写在 data/breakout/raw/exp/screen_w2_v1/prereg.json 和 research/screen/ledger.jsonl（8 行），主登记簿 138 行没动。t ≥ 1.0 的理由：筛选集的作用是淘汰；t < 1 的效应到开发集注定过不了。
6. **板块**：见上，相对标签没有推向北交所。
