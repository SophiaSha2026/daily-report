绝对门槛（过线就出、出了就准）：判定条文和试验纪律（写于 2026-10-18 03:40 北京，任何门槛结果看到之前）
================================================================================================

用户要求（2026-10-18 原话）：「给一个标准，过这个标准就出，不过就不出，但是出了的话就得够准。」「我不在乎几只，
也不在乎数量，我只在乎精度。甚至如果没有符合条件的股票，你都可以不出。」
产品形态 = 每只票每天算一个量 q，q >= 门槛就出，当天没过线就空榜。只评精确率。

0 尺子（沿用 research/precision/criteria.txt 第 0、1 节，同一份实现 common_pr.evaluate / Baseline / boot_ratio）
  精确率 P = Σ_d h_d / Σ_d n_d，h = 买得到命中 y_open（次日开盘起算 20 根内最高价涨超 50%，次日一字板记不中）。
  区间：按天影响函数 NW se（滞后 20）+ 块自举（块 20，4000 次）比值分位；报告以块自举区间为主。
  出票量 V、v̄ = V/D（含空榜日）、每月约 v̄ x 20 只、空榜天占比。
  对照：同量名次基线 B(k̄)（候选池内 log(1+ret20) 前 k̄ 名，k̄ = v̄，小数线性插值）和日配基线（每天前 n_d 名）。
  ΔP = P − P_B(k̄)，按天序列 u_d = h_d − h_B,d，NW t / 块自举同 precision。
  两段：筛选集 2022-01..2024-05（582 天）、开发集 2024-06..2025-12（387 天）。候选池 = research/polish pool.parquet 的
  pool 列（elig0 + 近 30 天无减持 / 未来 30 天解禁 < 5% / 近 60 天无增发），**不限名次**，全部候选池都可被门槛选中。
  2026-01..08 确认集标签一行不读。

1 「没碰过的」读法：门槛只用之前的数据
  逐月滚动（测试月 m = 2021-07 .. 2025-12，前 6 个月只为后面攒样本外分数，不进任何表）：
    a 训练：m 之前、按标签窗口净化的行（common_rc.train_mask：date < purge_cut 且 end20 < m-01，回看 36 个月）。
      负样本可以抽样（权重补回），正样本全留。
    b 样本外分数：训练好的模型给 m 月全部候选池行打分 s。这份 s 存下来，是唯一进评估的分数。
    c 校准 + 选门槛：只用 m 之前已经有样本外分数、且标签窗口已关（end20 < m-01）的最近 12 个月（不足 12 个月就用全部，
      至少 3 个月）。在这些行上做等渗回归 s -> p̂（单调），门槛 = p̂ >= τ（τ = 目标精确率）。等价于「过去 12 个月里
      分数 >= 这条线的票，实际精确率 >= τ」。τ 取 0.20 / 0.25 / 0.30 / 0.40 / 0.50。
      另一个口径并列：固定每月出票量上限不设；不设分数线以外的任何附加条件（否则就是子集规则，precision 已做）。
    d 两段的精确率因此都是「门槛从没见过标签」的读法；筛选集只用来挑方法族内的配置（模型类型、特征集、校准窗长、
      负样本抽样率、候选宇宙），开发集每个方法族只读一次最终配置。开发集的产物先落盘不打印，挑完配置再读。
  为什么校准用样本外分数而不是训练集内分数：训练集内分数对树模型是乐观的，按它选的线在新月上精确率必然掉下来。

2 方法族（每族一行记 ledger，每族 x 每个 τ 一行）
  F0 ret20 原值门槛：q = ret20，门槛同第 1c（在过去 12 个月样本外的 ret20 上做等渗 -> p̂）。它是「不训模型」的对照。
  F1 逻辑回归：<= 8 个原值输入（log(1+ret20)、log vol60、log turn20、amp20、log mcap、板块、nlu20、dist_hi60），当日内不做
     百分位、不中性化；每月重拟合。
  F2 LightGBM，日线原值特征 + ret20 名次 + 市场状态（候选池内可得的 40 来列）。
  F3 F2 + 非价格数据（龙虎榜 / 机构 / 两融 T-1 / 大宗 / 户数按公告日 / 调研按公告日，按 altdata features.py 的可得时点，
     算到全部候选池行）。
  F4 规则挖掘：在训练窗里按「精确率 >= τ 且支持数 >= N」搜 <= 3 个条件的合取（离散化的原值特征），在校准窗（样本外）
     上复核精确率 >= τ 才启用；给出可直接写进 daily.py 的句子。
  F5 集成：F2 / F3 多种子平均（只在 F2 / F3 有希望时做）。
  F6 并入 research/intraday / research/deepdata 的特征（它们落地了才做，没落地报告注明）。
  候选宇宙变体（属于配置，不是族）：全部候选池 对 候选池内 ret20 前 300。
  配置选择只看筛选集的「τ = 0.30 那一行的 ΔP 和 V」加「校准误差 |P − 平均 p̂|」。

3 每个 (族, τ) 报什么
  两段各自：V、出票天、空榜天占比、每月只数、P 和块自举区间、B(k̄) 和 ΔP（NW t）、日配 ΔP、平均 p̂（校准）、
  命中票 r20_open（20 根内最大涨幅）的分位数、逐年 P。合并 969 天 NW t、块自举 p、去最好月 t、滚动三月。

4 过线和「可上线」
  (族, τ) 算「可用」要同时满足：
    a 两段 V >= 150 且出票天 >= 60（估计得出来；再少区间半宽 > 12pp，读不出东西）
    b 两段各自 P 的块自举区间下界 >= 该段 B(10) 点估计（筛选 11.3% / 开发 16.5%：「出了就准」至少要比现行前 10 稳稳地高）
    c 两段各自 ΔP 对 B(k̄) >= 0，合并 NW t >= 2.5，块自举 p < 0.05（门槛要赢同量名次，否则只是缩名额）
    d 两段各自实际 P >= 0.8 τ（校准没有系统性虚高）
  只满足 a b 不满足 c：记「量换精度」（和缩名额一样），不算门槛有用。
  满足 c 不满足 a：记「方向」，不能上线。
  NW t <= −2.5 记「比名次差」。

9 功效和「最低出票量」
  区间半宽（块自举，设计效应 2~5）：V=150 时 P=0.3 约 ±11pp，V=300 ±8pp，V=600 ±5.5pp。
  对 B(k̄) 的 ΔP：precision 功效表在 v̄ 0.5~1 只/天时 NW se 2.5~4.8pp，MDE80 8~16pp。所以：
  门槛要「有用」，筛选集上至少要比同量名次高 8pp 以上；τ = 0.40 / 0.50 的行多半只能是「方向」。
