0 沿用
  精确率 P = Σ_d h_d / Σ_d n_d；区间 = 按天影响函数 NW se（滞后 20）+ 块自举（块 20，4000 次），报告以块自举区间为主。
  出票量 V、v̄ = V/D（含空榜日）、每月只数 v̄ x 20、空榜天占比。
  对照：同量名次基线 B(k̄)（候选池内 lret20 前 k̄ 名，小数线性插值，common_pr.Baseline）和日配基线（每天前 n_d 名）。
  ΔP = P − P_B(k̄)，按天 u_d = h_d − h_B,d，NW t / 块自举 p / 去最好月 / 滚动三月（common_gt.combined_judge）。
  两段：筛选集 2022-01..2024-05（582 天）、开发集 2024-06..2025-12（387 天）。候选池 = research/gate/table.parquet（= polish pool 列：
  elig0 + 近 30 天无减持 / 未来 30 天解禁 < 5% / 近 60 天无增发）。2026-01..08 确认集标签一行不读（所有表截到 2025-12-31）。
  逐月滚动：测试月 m 的模型只用 m 之前 36 个月、按 20 根净化的行（common_rc.train_mask：date < purge_cut(m) 且 end20 < m-01）。
  门槛 / 分位 / 可信度只用之前且标签窗口已关的数据。调参只在筛选集；开发集每族只读一次最终配置；开发集产物先落盘不打印。
  「可用」= gate 第 4 节四条：a 两段 V >= 150 且出票天 >= 60；b 两段 P 的块自举下界 >= 该段 B(10)；c 两段各自 ΔP >= 0，合并 NW t >= 2.5，
  块自举 p < 0.05；d（有目标精确率的臂）实际 P >= 0.8 τ。只满足 a b 记「量换精度」；满足 c 不满足 a 记「方向」；t <= −2.5 记「比名次差」。

1 第一部分：盲测「近期」的三种实现（都在 ret20 前 50 宇宙里出票；K、q、n 这些旋钮只在筛选集上挑）
  约定：T = 出票日；「T−20」= 同一只票往前第 20 根 K 线的那一行（按该票自己的 K 线序号，不按日历）。
  样本外分数 s(code, d) = research/gate/scores/lgb_price.npy（LightGBM，日线原值 38 列 + 市场状态 9 列，全候选池，每个测试月只用
  该月之前净化过的 36 个月训练）。s(code, d) 这一行的模型，训练集最晚一根 K 线的日期 < purge_cut(month(d)) <= d − 20 根，标签窗口
  end20 < month(d)-01 <= d。所以 s(code, T−20) 用到的最晚数据日期 <= T−20 的那根 K 线，训练集截止比它更早（至少再早 20 根）。
  V1 盲测 + 逐票验证
    看好 = s(code, T−20) 在 T−20 那天候选池内的分位 >= q（q ∈ {0.80, 0.90, 0.95, 0.98}，分位只在当天内算，不看未来）。
    走出来 = T 日 ret20 名次 <= K（K ∈ {10, 20, 50}）。
    出票 = 看好 ∩ 走出来，按 s(code, T)（模型看全部数据的 T 日分数）降序取每天前 n（n ∈ {1, 2, 3, 5, 10}）；n 可大于当天剩余只数（出不满）。
    关键对照（诊断，两段都看，记 diag）：在同一 ret20 名次档（1-3 / 4-10 / 11-30 / 31-50）里，按 s(T−20) 分位分三组（>= 0.95 / 0.80~0.95 /
    < 0.80）和「T−20 不在候选池」一组，各组精确率并排。差不出来就是模型没贡献，如实写。
    前视自检：(i) 把 T−20 换成 T（看好 = s(T) 分位 >= q），成绩应明显变化（它就成了「模型重排」，polish 已证伪）；
    (ii) 用到的日期逐行断言：feature 日期 = 该票第 20 根之前那一行的日期 < T，且分数来自 month(T−20) 的模型（gate scores 的月份就是行日期的月份）。
  V2 结构模型 + 动量确认
    训练行 = (特征取自该票 T−20 那一行的全部 FEATS_PRICE 列 + nbar、board，标签 = T 行的 y_open)。特征里没有任何一列用到 T−20 之后的价格。
    每个测试月 m 用 m 之前 36 个月、end20(T 行) < m-01 且 T < purge_cut(m) 的训练行（common_rc.train_mask 同一条规则作用在 T 行上）；
    负样本抽 15% 权重补回；LightGBM 浅树（gate LGB_PARAMS shallow），种子 7。全候选池训练，样本外分数 s2(code, T) 落 scores/v2_*.npy。
    出票 = ret20 名次 <= K 的票里按 s2 降序取每天前 n（K ∈ {10, 20, 50}，n ∈ {1, 2, 3, 5, 10}）；另一个读法 = s2 当天候选池分位 >= q 的硬门槛。
    对照：同量名次基线 B(k̄)。另印「s2 当天分位三组 × 名次档」的诊断表。
    自检：(i) 特征列名和取值逐行断言来自 T−20 行；(ii) 标签每天内打乱重训一次，顶部精确率应回到名次档基准。
  V3 逐票的模型可信度
    对每只票、每个 T，取它过去全部已关窗（end20 < T）且有样本外分数的行，可信度 c = Σ(y − s) / (n + n0)，n0 = 20（经验贝叶斯收缩到 0）；
    用 merge_asof 按 end20 对齐，保证只用 T 之前关窗的行。
    出票 = ret20 名次 <= K 且 c > 0（或 c 在当天候选池内分位 >= q）的票，按 s(T) 降序取前 n。
    V3b（不靠模型的同类）：这只票过去进 ret20 前 10 的已关窗次数 n_r 和命中 h_r，c_r = (h_r + a·p0) / (n_r + a)，a = 5，p0 = 该段之前全部前 10 的
    累计精确率（只用过去）；出票 = 前 10 里 c_r 最高的 n 只（「以前走出来过」对「第一次」）。
    对照同上。
  所有 V1 / V2 / V3 的筛选集网格每个配置记 kind=screen；每个实现在开发集只读一个配置（筛选集 ΔP 最大且过量门槛者），记 kind=arm。
  打乱自检（教训 32）：V1 / V3 把 top50 表的 hit 每天内随机置换一次，重算 ΔP，应在 ±2 se 内回到 0。

2 第二部分：底层原理和杠杆
  2a 先写（报告「瓶颈」一节，实测之前写定公式，数字从数据里算）：
     正样本率 π、按天聚集的设计效应 DE = NW 方差 / iid 方差（在前 10 命中序列上实测）、有效样本 n_eff = n / DE；
     分辨 Δ = 2pp 精确率差（P ≈ 0.15，配对重合 ρ）所需有效票数 n_eff = 2(1−ρ)·(z_c + z_80)^2·P(1−P)/Δ^2，换算成按每天 10 只需要多少年；
     「挑日子不挑票」：P(top) 分解为 跨天配量（Σ n_d π_d / Σ n_d − π̄）+ 当天内增量；打乱标签后开发集仍 11~13% 说明第一项占了多少。
  2b 杠杆（每根一个族，筛选集挑配置、开发集一次）：
     L1 样本量 / 行情多样性：新浪 stock_zh_a_daily 拉 2005 年起的不复权 OHLCV + 股本 / 换手 + 前复权因子（和 research/leak/fetch_unadj.py 同一条路，
        多进程 4 路，北京 16:00~18:30 不发请求），先实测能拉到多早、退市票给不给（用真实的已退市代码试，教训 2），幸存者偏差写清楚。
        在长历史上按同一套 FEATS_PRICE 口径建特征和 y_open 标签；训练窗从 36 个月放到「2010-01 起全部」（和 36 个月对照），
        测试仍是两段；看模型顶部精确率对 B(k̄) 的 ΔP 是否改善。
     L2 去掉日级成分：LightGBM 二分类加 init_score = logit(当天候选池基准率)（训练时按天的真实基准率，等价于日固定效应 / 按天分层的
        条件逻辑回归的树版本；预测时偏移是每天常数，不影响当天内排序）；对照同配置不加偏移。
     L3 更多标签信息：目标换成 r20_open 的变换（log1p 截断在 [−0.5, 2]）做回归；多任务近似 = 到达 30% / 50% / 80% 三个二分类的分数当天内分位平均。
        最终仍按 y_open（50%）评估。
     每根杠杆都在 ret20 前 50 宇宙内按分数取每天前 n（n ∈ {1,2,3,5,10}）对 B(n)，同时印全候选池前 n（对照 gate 的「崩盘反弹簇」问题）。
  2c 打乱自检：L2 的训练标签每天内打乱一次。
