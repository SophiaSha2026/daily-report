# 命中率打磨研究（research/polish，2026-10-17）

（Fable 5.1 high 子代理写成，主会话落盘。数字见 research/polish/results_*.txt；判定条文 criteria.txt 在臂跑之前写定。）

## 一屏结论

**最好的配置就是现在的 ret20 规则本身，本轮没有找到任何能稳定提高「每天前 10 买得到命中」的改法。**

- 成绩（买得到口径，每天前 10）：筛选集 2022-01..2024-05 **11.34%**（NW 95% 区间 9.2~13.5，582 天），开发集 2024-06..2025-12 **16.54%**（12.4~20.7，387 天），合并 969 天 **13.42%**（11.2~15.7）。候选池基准 1.62 / 4.32%。前向 2026-09-01..09-10（只有 8 天窗口关闭）1/79 = 1.3%，当期候选池基准 1.34%，冷市，8 天说明不了任何事。
- 对 ret20 的增益：筛选集 92 个规则配置 + 22 个重排模型配置，没有一个赢过 0.3pp（族内最好 +0.07 / +0.27pp，t 0.2 / 0.6）；拿到开发集一次看的两个正式臂：lm_10_20 合并 +0.01pp（NW t 0.04），rr_lr_k50_min −0.46pp（t −0.75，开发集 −1.58）。族 p 0.73 / 0.95。
- 天花板：ret20 前 50 内，连带时间泄漏的同期交叉拟合（按股票 5 折 LightGBM，35 个日线特征 + 名次）也只到 10.1 / 16.4%（对 ret20 −1.25 / −0.13pp）；按月交错折（含未来月）12.6 / 17.2%（+1.3 / +0.7，t 1.7 / 0.5）。**日线量价在这个尺子上的乐观上界 ≈ ret20 + 1pp，即筛选集 12~13%、开发集 17~18%**；要到 20% 以上需要前 50 内 AUC 0.60（开发集）~0.80（筛选集），现有特征做不到。
- 上线建议：**排序规则不动**。有一处生产口径要改（对齐，不是实验）：生产 `elig = 训练表里 >= 120 行` 加上 build 的 120 根预热，实际把上市不满约 240 根的票挡在规则候选池外，而验证时的候选池只要 120 根；按生产口径复算，两段同号 **−0.41pp（NW t −2.14，筛选 −0.55 / 开发 −0.21）**。放宽到 60 根反而 −0.10（60~119 根的票命中只有 3.7%），所以 120 根是对的。不需要确认集。

## 纪律和预算（criteria.txt）

- 基线 = 同循环 ret20，候选池同 rulecore（elig0 + 减持 / 解禁 / 增发剔除），按天配对，两段各自同号 + 合并 969 天 NW t（滞后 20）>= max(2.5, 族门槛) + 块自举 p + 去最好月 t >= 2 + 滚动三月 >= −5pp + 前 30 同号；按天 AUC 不作淘汰条件。
- 功效（results_power.txt）：和基线前 10 重合 90 / 70 / 50 / 0% 的臂，NW se 0.15 / 0.30 / 0.45 / 0.80pp，MDE80(c=2.5) 0.5 / 1.0 / 1.5 / 2.7pp；真实近邻臂比合成臂 se 更大（ret10 重合 53% se 0.46，ret40 48% se 0.68）。
- 调参只在筛选集；开发集每族只看一次。rethink 已在开发集看过 ret10 / ret5 / ret60 / vol60 / amp20 等单量规则，含这些量的臂算第二次看。
- 计数：筛选集调参 114 个配置（不进开发集）；开发集正式臂 2 个（evalkit 新族 breakout_y50_top10_polish）；另记 2 次 look（生产口径核对、剔除代价）+ 1 次前向。2 臂最大 t 零分布 95% 分位 1.90 → c 2.5；严格门槛（旧族 74 + 本族）3.21。

## 生产口径对齐（主会话 2026-10-17 已改 daily.py）

规则线的候选池「上市满 120 根」按 daily.parquet 的根数算，不按训练表行数（训练表每只票少了 build.MIN_HIST=120 根预热，等于要求约 240 根）。验证的 11.34 / 16.54 / 15.19% 都是 120 根口径。模型影子清单继续用训练表口径。
