# 精确率优先的清单规则（research/precision，2026-10-18）

（Fable 5.1 high 子代理写成，主会话落盘。判定条文 criteria.txt 在任何前沿表之前写定，数字见 results_*.txt，逐步记录 progress.txt，看数记 ledger.jsonl。没进 16:00~18:30；没改 src / state / data / out_*；2026-01..08 标签一行没读。）

目标来自用户 2026-10-18：「我不在乎几只，也不在乎数量，我只在乎精度。甚至如果没有符合条件的股票，你都可以不出，但如果出，必须保证高精度。」即优化精确率（出的票里买得到命中的比例），清单长度可变、可空榜。

## 一屏结论

**在这把尺子上，能用的只有「名次」这一个旋钮：ret20 前 2 名两段精确率 15.0% / 19.4%，前 10 名 11.3% / 16.5%。558 个子集规则在筛选集上没有一个能和「只缩名次」区分开；正式臂 0 个，开发集没为任何子集规则看过。**

- 尺子：精确率 P = 出的票里买得到命中（y_open）的比例，按票池化；区间按天块自举（块 20）。比较对象是**同等出票量的名次基线 B(k̄)**（ret20 前 k̄ 名，k̄ 可为小数），不是前 10。候选池同 polish（elig0 + 减持 / 解禁 / 增发剔除），规则只能在候选池 ret20 前 50 里选子集。

- 前向 2026-09-01..10-16（只看一次）：窗口已关只有 8 天，候选池基准 1.34%，B(1/2/3/5) 0 命中，B(10) 1/79；四个筛选集最好的子集规则 0 命中。冷市 8 天说明不了任何事。
- **上线建议：不往 daily.py 加任何子集规则。** 唯一站得住的做法是把名额从 10 缩到 2~3（只改 CAP_A 一类常量），代价是 65~73% 的交易日一只都不中、筛选集有 4 个月整月零命中，而且 B(2) 对 B(10) 的 +3pp 在开发集 t 只有 1.2。精确率区间下界（9.7% / 13.7%）并不高于 B(10) 的点估计（11.3 / 16.5），不满足「出了就高精度」的上线标准，只能算「量换精度」的权衡，由用户定。

## 判定条文要点（criteria.txt）

- 尺子：P = Σh/Σn，按天影响函数 u_d = h_d − P·n_d 给 NW se（滞后 20），块自举比值给区间。不用按天精确率均值（空榜日没定义，1 只的天和 10 只的天同权）。
- 匹配量基线 B(k̄)：k̄ = 规则的平均日出票量，分数 k 线性插值；ΔP = Σ(h_R − h_B)/V_R，按天序列进 NW t / 块自举 / 族最大 t。并列印「日配基线」（每天取前 n_d 名）归因选票 vs 挑日子。
- 过线：两段 ΔP >= 0；合并 NW t >= max(2.5, 族门槛)；块自举 p < 0.05；去最好月 t >= 2；滚动三月 >= min(−5pp, 零分布 5% 分位)；出票量门槛 筛选 V >= 300 且出票天 >= 100、开发 V >= 150 且 >= 60；功效 筛选 ΔP >= 表 MDE80；阈值邻域同号（辅助）。
- 纪律：调参只在筛选集；开发集每族一次、正式臂 <= 8；粗分组诊断允许看两段并记 diag（本轮 22 条，进严格门槛计数）；k̄ > 10 不考虑；不训新模型。
- 功效表（任何臂之前算）：前 10 内随机子集对 B(k̄) 的 ΔP NW se：筛选集 0.5 / 1 / 2 / 3 / 5 只/天 → 2.9 / 2.5 / 1.9 / 1.4 / 0.8pp，MDE80 9.6 / 8.2 / 6.3 / 4.8 / 2.8pp；开发集 4.8 / 4.2 / 2.7 / 2.1 / 1.3。精确率自身区间半宽：筛选 V≈290 ±4.0pp，开发 V≈190 ±6.2pp。

## 正式臂判定

无。405 个过量门槛的筛选集配置里，ΔP >= 表 MDE80 的只有 k̄ = 10 的基线自身；按臂自身 se 算 MDE 也只有两个和基线几乎重合的（r1/r2 & ret20 >= 0.5，+0.05 / +0.11pp）。正式臂 0 个，开发集的网格序列没有读。严格门槛计数：旧族 74 + polish 2 + 本族 diag 22 条 + 臂 0。

## 为什么子集规则赢不了名次

1. 名次本身就是最强的精确率维度：1~3 名 14.1 / 17.7%，4~10 名 10.2 / 16.1%，11~30 名 6.1 / 12.8%，31~50 名 4.8 / 11.8%。任何条件要在 1~3 名内再切一刀才可能超过 15~19%，而 1~3 名内两段同向的条件只有「非主板」「无跌停」「冷市」，各 +2~4pp，切完 0.5~1 只/天，se 2.5~3pp。
2. 很多在前 50 里有分辨力的维度到了 1~3 名内反号：换手高、融资余额增、影子模型分高。它们分辨的是「11~50 名里谁像 1~3 名」，到了 1~3 名已经没有增量（和 altdata 报告「条件命中强、边际没有」同一件事）。
3. 精确率尺子的噪声比命中率尺子大：出 0.5~1 只/天时 NW se 2.5~3pp，筛选集 582 天只能分辨 8~10pp 的差。两段一致的 +2~5pp 既不能确认也不能否定，而嵌套逐月读法说明在这堆 +2~5pp 里挑最好的会挑到噪声（开发集 −4.7pp）。
