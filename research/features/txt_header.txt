特征文献调研目录（research/features/catalog.json 的说明，2026-10-15）

目标：次日开盘买入后 20 个交易日内最高价涨超 50%（买得到口径，次日一字不可买）。
这是右尾概率预测，不是收益排序。文献里「对均值收益为负」的彩票类因子（MAX、偏度、特质波动、
低价、小盘），对「右尾概率」应当是正向的，方向交给模型学，不要照搬文献的符号。

可用数据：daily.parquet 的 open high low close（前复权）、volume amount（原值）、turnover、
outstanding_share（逐日流通股本），股东户数（按公告日），自算筹码，板块。

一、怎么读 catalog.json

每条因子的字段：
  id / rank      id 按族排；rank 是总排序（1~41），priority 3 的统一记 42，不建议先做
  family         族（A~J）
  formula        公式。记号见 notation：r 日收益，ovn 隔夜 O/C_{t-1}-1，intra 日内 C/O-1，
                 TR 换手率，FS 流通股本，mkt 当日全市场等权均值，brd 同板块均值，rank_cs 当日全市场排名
  windows        建议窗口（交易日）
  source_url     出处（论文页 / 公式表 / 复现代码）
  verified       出处核到哪一层：公式表或复现代码已读 / 摘要级 / 据记忆待核对 / 自拟
  rationale      经济含义，以及和「20 天涨 50%」的关系
  overlap        和 Alpha158（altpath 已做的 142 列）与生产 40~50 列的重叠判断
  cost           计算成本
  lookahead_risk 偷看风险（全部只用 t 日收盘及以前）
  priority       1 先做 / 2 第二批 / 3 重叠高或理由弱

二、三条通用的口径约束（实现时必须守）

1. 量能一律用换手率 TR，不用成交股数 V。V 是原值，送转日整段跳升，会伪造放量（features.py 注释、教训同源）。
2. 不要用前复权的绝对价位（1/close、价位水平、C×FS 当市值）。前复权价会被之后的分红送转整体改写，
   等于把未来的除权信息带进历史。需要价位和市值时用 AMT/V（当天不复权均价）。
3. VWAP = AMT/V 是不复权价，不能和前复权的 C 直接比（altpath 因此删了 VWAP0）。WQ101 和国君 191 里
   带 VWAP 的公式一律改用典型价 (H+L+C)/3，或只在窗口内不跨除权日时用 VWAP 自身的比值。

三、三个因子库的处理结论

WorldQuant 101（Kakushadze 2016，arXiv 1601.00991；公式取自 yli188 复现代码注释，逐条对过原式）：
  平均持有期 0.6~6.4 天，是超短周期的均值回归 / 量价相关组合，和 20 天右尾目标关系弱。101 条里 48 条用到
  VWAP 或 IndNeutralize（其中 18 条要行业中性化，我们没有时点一致的行业），另有大量 rank(correlation(...)) 的量价相关，
  和 Alpha158 的 CORR / CORD 同类（altpath 已证量能族无增益）。只收了 #101（收盘强度）和 #55（区间位置与量的相关）
  两条做对照，都在 priority 3。

国泰君安 191（2014 年研报《基于短周期价量特征的多因子选股体系》；公式取自 wukan1986/alpha_examples 的 alpha191.txt）：
  大部分是 WQ101 的变体或经典技术指标（RSI、KDJ、BR/AR、CCI、MACD、ADX）。191 条里 4 条要基准指数（#75、149、181、182），
  #30 要 FF 三因子，另有 12 条在该公式表里因算子（REGBETA / SUMAC / SUMIF / 递归 SELF）未实现而注释掉；
  可用的 174 条里 36 条带 VWAP。收进来的：#23（相对波动指数，上行半方差）、#11/#60（CLV 加权累计）、
  #109 / #188（振幅加速 / 冲击）、#118（开盘后上攻力度）、#110（类 BR）、#144（Amihud 下跌日版）、#166（偏度）。
  其余和 Alpha158 的 ROC / MA / RSV / CNTP / SUMP 重叠或只差一个平滑方式。

qlib Alpha158 / Alpha360（qlib/contrib/data/loader.py 已读）：
  Alpha158 = K 线 9 列 + 价格 4 列 + 29 个算子 × 窗口 5/10/20/30/60，altpath 已全做（去掉 VWAP0）。
  它没有：隔夜 / 日内拆分、三阶四阶矩、日收益极值、对市场的残差、市值和价位、换手率自身分位、
  60 日以上窗口、按价位或振幅切割的统计量。下面的目录主要就是补这几块。
  Alpha360 是 60 天原始序列（价除以今日收盘、量除以今日量），给序列模型用，列为 priority 3。
