特征文献调研目录（research/features/catalog.json 的说明，2026-10-15）

目标：次日开盘买入后 20 个交易日内最高价涨超 50%（买得到口径，次日一字不可买）。
这是右尾概率预测，不是收益排序。文献里「对均值收益为负」的彩票类因子（MAX、偏度、特质波动、
低价、小盘），对「右尾概率」应当是正向的，方向交给模型学，不要照搬文献的符号。

可用数据：daily.parquet 的 open high low close（前复权）、volume amount（原值）、turnover、
outstanding_share（逐日流通股本），股东户数（按公告日），自算筹码，板块。

一、怎么读 catalog.json

每条因子的字段：
  id / rank      id 按族排；rank 是总排序（1~41），priority 3 的统一记 42，不建议先做
  family         族（A~J）
  formula        公式。记号见 notation：r 日收益，ovn 隔夜 O/C_{t-1}-1，intra 日内 C/O-1，
                 TR 换手率，FS 流通股本，mkt 当日全市场等权均值，brd 同板块均值，rank_cs 当日全市场排名
  windows        建议窗口（交易日）
  source_url     出处（论文页 / 公式表 / 复现代码）
  verified       出处核到哪一层：公式表或复现代码已读 / 摘要级 / 据记忆待核对 / 自拟
  rationale      经济含义，以及和「20 天涨 50%」的关系
  overlap        和 Alpha158（altpath 已做的 142 列）与生产 40~50 列的重叠判断
  cost           计算成本
  lookahead_risk 偷看风险（全部只用 t 日收盘及以前）
  priority       1 先做 / 2 第二批 / 3 重叠高或理由弱

二、三条通用的口径约束（实现时必须守）

1. 量能一律用换手率 TR，不用成交股数 V。V 是原值，送转日整段跳升，会伪造放量（features.py 注释、教训同源）。
2. 不要用前复权的绝对价位（1/close、价位水平、C×FS 当市值）。前复权价会被之后的分红送转整体改写，
   等于把未来的除权信息带进历史。需要价位和市值时用 AMT/V（当天不复权均价）。
3. VWAP = AMT/V 是不复权价，不能和前复权的 C 直接比（altpath 因此删了 VWAP0）。WQ101 和国君 191 里
   带 VWAP 的公式一律改用典型价 (H+L+C)/3，或只在窗口内不跨除权日时用 VWAP 自身的比值。

三、三个因子库的处理结论

WorldQuant 101（Kakushadze 2016，arXiv 1601.00991；公式取自 yli188 复现代码注释，逐条对过原式）：
  平均持有期 0.6~6.4 天，是超短周期的均值回归 / 量价相关组合，和 20 天右尾目标关系弱。101 条里 48 条用到
  VWAP 或 IndNeutralize（其中 18 条要行业中性化，我们没有时点一致的行业），另有大量 rank(correlation(...)) 的量价相关，
  和 Alpha158 的 CORR / CORD 同类（altpath 已证量能族无增益）。只收了 #101（收盘强度）和 #55（区间位置与量的相关）
  两条做对照，都在 priority 3。

国泰君安 191（2014 年研报《基于短周期价量特征的多因子选股体系》；公式取自 wukan1986/alpha_examples 的 alpha191.txt）：
  大部分是 WQ101 的变体或经典技术指标（RSI、KDJ、BR/AR、CCI、MACD、ADX）。191 条里 4 条要基准指数（#75、149、181、182），
  #30 要 FF 三因子，另有 12 条在该公式表里因算子（REGBETA / SUMAC / SUMIF / 递归 SELF）未实现而注释掉；
  可用的 174 条里 36 条带 VWAP。收进来的：#23（相对波动指数，上行半方差）、#11/#60（CLV 加权累计）、
  #109 / #188（振幅加速 / 冲击）、#118（开盘后上攻力度）、#110（类 BR）、#144（Amihud 下跌日版）、#166（偏度）。
  其余和 Alpha158 的 ROC / MA / RSV / CNTP / SUMP 重叠或只差一个平滑方式。

qlib Alpha158 / Alpha360（qlib/contrib/data/loader.py 已读）：
  Alpha158 = K 线 9 列 + 价格 4 列 + 29 个算子 × 窗口 5/10/20/30/60，altpath 已全做（去掉 VWAP0）。
  它没有：隔夜 / 日内拆分、三阶四阶矩、日收益极值、对市场的残差、市值和价位、换手率自身分位、
  60 日以上窗口、按价位或振幅切割的统计量。下面的目录主要就是补这几块。
  Alpha360 是 60 天原始序列（价除以今日收盘、量除以今日量），给序列模型用，列为 priority 3。

四、按族的目录（rank 升序）

【A_隔夜日内分离】8 条
  F001 ovn_mom（priority 1，rank 5，窗口 [5, 20, 60]）
    公式：MEAN(ovn, d)，ovn_t = O_t/C_{t-1}-1
    含义：Lou, Polk, Skouras (2019 JFE)：隔夜和日内收益各自多年持续、互相反转；动量利润几乎全在隔夜，隔夜由散户 / 开盘集合竞价推动。妖股启动前常见连续高开（散户追价在竞价里体现），隔夜累计是「散户关注度」的日线代理。
    重叠：Alpha158 只有当天 OPEN0=O/C，没有隔夜累计；生产特征没有。不重叠。
    成本：低（一次滚动均值）；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://personal.lse.ac.uk/polk/research/TugOfWar.pdf（学术；摘要级（概念和方向已核，公式按定义写））
  F002 intra_mom（priority 1，rank 9，窗口 [5, 20, 60]）
    公式：MEAN(intra, d)，intra_t = C_t/O_t-1
    含义：同上，日内段由机构主导。和隔夜同时入模，模型可学两者的组合（ROC = 隔夜 + 日内的复合）。
    重叠：Alpha158 KMID 只有当天；ROC 是两者之和。中度重叠（ROC 已知时只多一个自由度）。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://personal.lse.ac.uk/polk/research/TugOfWar.pdf（学术；摘要级（概念和方向已核，公式按定义写））
  F004 ovn_dist（priority 2，rank 11，窗口 [20]）
    公式：MEAN(|ovn_t - mkt(ovn_t)|, 20)（方正「球队硬币」的隔夜距离）
    含义：隔夜涨跌幅全市场最平静，个股偏离市场均值越多，说明隔夜有个股层面的信息 / 关注度冲击。极端上涨前的「异动」常先出现在开盘。
    重叠：不重叠（Alpha158 没有隔夜，生产没有）。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/个股动量效应的识别及球队硬币因子（券商（方正金工，QuantsPlaybook 复现）；公式表 / 复现代码已读）
  F039 apm_ovn_intra（priority 2，rank 16，窗口 [20]）
    公式：APM 日线改写：取近 20 天，隔夜段 ovn_t 和日内段 intra_t 共 40 个观测，对同段的 mkt 收益做一次时间序列回归 r = α + β·R + ε；δ_t = ε^ovn_t - ε^intra_t；stat = MEAN(δ)/(STD(δ)/√20)；再对当日 rank_cs(ret20) 做截面回归取残差
    含义：APM（开源证券）原版比较上午和下午的残差收益：知情交易集中在上午。日线只能拆成隔夜 / 日内；stat 高 = 个股的超额收益主要在盘前到达（消息 / 竞价抢筹），对散户驱动的极端上涨是正向线索。
    重叠：和 ovn_mom / ovn_intra_tug 同源，但去掉了市场部分并做成 t 统计量。中度。
    成本：中（每只票 20 天一次 OLS）；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/APM因子模型（券商（开源证券 APM，QuantsPlaybook 复现）；公式表 / 复现代码已读）
    备注：原版要上午 / 下午分时收益（见需要新数据一节）。复现代码 issue #25 指出它按日期分组回归退化成截面去均值；实现时按研报口径每只票合并 40 个观测回归
  F005 coin_flip_ret（priority 2，rank 19，窗口 [20]）
    公式：MEAN(r_t * sign(ΔTR_t - mkt(ΔTR_t)), 20)，ΔTR_t = TR_t - TR_{t-1}；同法可换 ovn / intra（方正「球队硬币」换手率翻转版）
    含义：方正金工：换手率变化低于市场均值的日子视为「硬币」（无信息、该反转），高于的视为「球队」（有信息、该延续）。把收益按是否放量加签名后再平均，区分「放量涨」和「缩量涨」。
    重叠：和 Alpha158 CORD（收益和量变化的相关）概念近，但这里是加签名均值；生产 up_vol_share20 部分重叠。中度。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/个股动量效应的识别及球队硬币因子/FactorZoo/SportBetting.py（券商（方正金工）；公式表 / 复现代码已读）
    备注：复现代码 get_coins_team：factor * sign(baseline - cs_mean)，opr='lt'。原报告是月频选股，日频滚动 20 天是我们的改法。
  F007 gap_up_cnt（priority 2，rank 23，窗口 [20, 60]）
    公式：COUNT(L_t > H_{t-1}, 20)（未回补的跳空缺口天数）；另一列 COUNT(O_t/C_{t-1}-1 > 0.03, 20)
    含义：强势股启动时出现不回补的跳空，是抢筹的痕迹。和 20 天涨 50% 的连板行情直接相关。
    重叠：涨停生态 lu 列（近 20 天封板次数）部分重叠：一字连板必然跳空。中度。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：自拟（经典技术分析：突破缺口）（技术分析；自拟，无外部出处）
  F003 ovn_intra_tug（priority 2，rank 39，窗口 [20]）
    公式：rank_cs(SUM(ovn,20)) - rank_cs(SUM(intra,20))
    含义：「拔河」：隔夜涨、日内跌说明散户追、机构卖；对 20 天涨 50% 这种散户驱动行情，方向可能和美股相反（隔夜强的票更可能被炒作），让模型自己学符号。
    重叠：和 ovn_mom / intra_mom 线性相关，二选一或都给树模型。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://personal.lse.ac.uk/polk/research/TugOfWar.pdf（学术；摘要级（概念和方向已核，公式按定义写））
  F006 ovn_vol_share（priority 3，未排序，窗口 [20]）
    公式：STD(ovn,20) / (STD(ovn,20)+STD(intra,20))
    含义：波动集中在隔夜说明信息 / 情绪在盘后到达（消息、竞价抢筹），集中在日内说明盘中博弈。
    重叠：Alpha158 STD 是收盘价波动，不拆段。不重叠。

【B_波动收缩与突破】8 条
  F040 ideal_amplitude（priority 1，rank 8，窗口 [20]）
    公式：近 20 天每日振幅 amp = H/L - 1；按收盘价在这 20 天里的分位切：收盘价最高的 λ 那些天振幅均值 V_high，最低的 λ 那些天 V_low；V = V_high - V_low，λ = 0.25（研报扫 0.2~1.0）。剔除停牌和一字涨跌停后的日子，有效天数 < 10 置空
    含义：开源证券「理想振幅」：高价位振幅大 = 高位多空分歧（派发），低价位振幅大 = 低位换手（吸筹）。研报 IC −0.075（λ=20%），中证 500 比沪深 300 强。对我们是「高位放波动」的反向信号，λ 越小越强。
    重叠：生产 range_compress、Alpha158 STD 只看振幅水平，不按价位切。不重叠。
    成本：低（20 天窗口内排序）；偷看：低：只用比值，前复权的整体缩放不影响；不要用绝对价位
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/振幅因子的隐藏结构（券商（开源证券市场微观结构 7，QuantsPlaybook 复现）；公式表 / 复现代码已读）
  F008 pcf_conv（priority 1，rank 10，窗口 [120]）
    公式：-LOG(1 + STD([C, MA5, MA10, MA20, MA60, MA120]) / C)（多根均线的离散度，按 C 归一）
    含义：开源证券（91）均线收敛：均线粘合越紧，形态越「收」，后续突破概率越大。妖股启动前多是长期横盘、均线粘合。
    重叠：生产 ma_align（排列方向）、boll_width（20 日）概念相邻但不同：这里是 6 根均线的离散度。Alpha158 MA 是单根乖离。低到中度。
    成本：低；偷看：低：只用比值，前复权的整体缩放不影响；不要用绝对价位
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/开源证券-开源量化评论（91）：形态识别，均线的收敛与发散/FactorArithmetic/convergence_factor.py（券商（开源证券，QuantsPlaybook 复现）；公式表 / 复现代码已读）
    备注：复现代码直接对后复权价求 std，没有按价格归一，价位高的票天然大；我们必须除以 C，否则是价位因子。
  F041 amp_cut_mom（priority 2，rank 24，窗口 [120]）
    公式：近 N=120 天，按每日振幅 H/L-1 排序，取振幅最低的 λ=30% 那些天的日收益之和（A 因子，动量）；振幅最高的那些天的收益之和是 B 因子（反转）
    含义：开源证券（开源量化评论 3）：A 股反转强、动量弱，但低振幅日的涨跌是「动量」，高振幅日的涨跌是「反转」。低振幅日在稳步上行，说明有资金在不显眼地推，对后续加速是正向；研报 IC 0.021（λ=30%，N=120）。
    重叠：Alpha158 ROC 是全部天数的和，不切；生产 rs60 同。低。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/A股市场中如何构造动量因子？（券商（开源证券）；公式表 / 复现代码已读）
  F009 trcf_conv（priority 2，rank 27，窗口 [120]）
    公式：-LOG(1 + STD([TR, MA5(TR), MA10(TR), MA20(TR), MA60(TR), MA120(TR)]) / MA120(TR))
    含义：换手率均线收敛（TRCF）：成交长期平稳、没有异动，是「冷清很久」的连续版，和长期调整突破的横盘段同一个意思。
    重叠：生产 vol_compress、turn_std20 部分重叠（20 日窗口）；这里 120 日多均线。中度。
    成本：低；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/开源证券-开源量化评论（91）：形态识别，均线的收敛与发散/README.md（券商（开源证券）；公式表 / 复现代码已读）
  F013 box_breakout（priority 2，rank 28，窗口 [60, 120]）

    含义：窄平台 + 收盘突破平台上沿。宽平台的突破和窄平台的突破含义不同，交互项让树更容易学。
    重叠：Alpha158 MAX60 / RSV60 和生产 range_compress 各覆盖一半，交互项没有。中度。

  F012 nr_rank（priority 2，rank 29，窗口 [7, 20]）

  F011 range_shock（priority 2，rank 30，窗口 [11]）

【C_极端收益与偏度】10 条
  F018 past_jackpot（priority 1，rank 1，窗口 [250]）
    公式：过去 250 天里「已关闭」的窗口内是否出现过 20 天涨 50%：MAX_{s ≤ t-20} [MAX(H_{s+1..s+20})/O_{s+1} - 1]，取 s 在 [t-250, t-20]；另列次数 COUNT

【H_残差动量与特质波动】3 条
  F032 idio_vol（priority 1，rank 4，窗口 [20, 60]）
    公式：STD(e, 20)，e 为上式残差（Ang-Hodrick-Xing-Zhang 2006 的特质波动）
    含义：特质波动高的票均值收益低（AHXZ），但右尾大；BCW 说加入 MAX 后特质波动之谜反转。对极端上涨概率应当是正向。
    重叠：Alpha158 STD 是总波动（含市场）；生产 atr_ratio 是比值。中度。
    成本：中；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://alphaarchitect.com/hot-off-the-jfe-press-maxing-out-your-returns/（学术；摘要级（概念和方向已核，公式按定义写））
  F031 resid_mom（priority 1，rank 7，窗口 [20, 120]）
    公式：120 天回归 r = a + b·mkt + c·brd + e（窗口不含最近 20 天）；用系数算最近 20 天残差 e，resid_mom = SUM(e,20) / STD(e,20)
    含义：Blitz, Huij, Martens (2011)：剔除共同因子暴露后的动量，风险调整后利润约为普通动量两倍。对我们：剔除「今天大盘 / 板块好」的部分后的个股独立强度。
    重叠：生产 rs20 / rs60 是相对强弱（减市场），没有按 beta 剔除和按残差波动标准化。中度。
    成本：中（滚动 OLS）；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://repub.eur.nl/pub/22252（学术；摘要级（概念和方向已核，公式按定义写））
  F033 idio_skew（priority 2，rank 38，窗口 [60, 120]）
    公式：SKEW(e, 60)（剔除市场后的偏度）
    含义：Boyer-Mitton-Vorkink (2010) 的预期特质偏度和 Conrad 的 jackpot 都指向特质右尾。
    重叠：和 skew_ret 高度相关，二选一。
    成本：中；偷看：低：只用 t 日收盘及以前的 OHLCV
    出处：https://ideas.repec.org/a/eee/jfinec/v113y2014i3p455-475.html（学术；据记忆，实现前核对原文）

【I_筹码与成本】3 条
  F034 chip_moments（priority 2，rank 33，窗口 [60]）
    公式：换手率衰减加权的成本分布（权重 w_s = TR_s · Π_{u>s}(1-TR_u)，窗口 60）上，x_s = 1 - C_s/C_t：ARC = Σw·x（平均浮盈），VRC = 方差，SRC = 偏度，KRC = 峰度
    含义：筹码分布的四阶矩。SRC / KRC 描述套牢盘是集中在上方一块还是分散，突破时上方抛压的形状。
    重叠：生产 chip_win（获利盘）、chip_conc90、chip_dev 覆盖一、二阶；三、四阶不重叠。
    成本：中（每只票滚动 60 天加权）；偷看：低：只用比值，前复权的整体缩放不影响；不要用绝对价位
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/筹码因子/scr/turnover_coefficient_ops.py（券商（QuantsPlaybook 筹码因子复现）；公式表 / 复现代码已读）
  F036 apb（priority 2，rank 41，窗口 [5, 30]）
    公式：APB_d = MEAN(VWAP, d) / (Σ VWAP·V / Σ V)，d = 5, 30（窗口内跨除权日则置空）
    含义：量价关系度量买卖压力：成交集中在低价位（加权均价低于算术均价）说明低位吸筹。
    重叠：不重叠（生产没有用 VWAP）。
    成本：低；偷看：低；VWAP 不复权，跨除权日比值会错，必须按除权日切断（流通股本跳变或 C/C_{t-1} 与 AMT/V 比值跳变识别）
    出处：https://github.com/hugo2046/QuantsPlaybook/tree/master/B-因子构建类/基于量价关系度量股票的买卖压力/py/CalFunc.py（券商（QuantsPlaybook 复现）；公式表 / 复现代码已读）
  F035 cgo（priority 3，未排序，窗口 [100, 250]）
    公式：CGO = (C - RP)/C，RP = Σ_{k≥1} V_{t-k}·Π_{j<k}(1-TR_{t-j})·P_{t-k} / 归一，P 用 TP=(H+L+C)/3，窗口 100
    含义：Grinblatt-Han (2005) 处置效应 / 资本利得悬置：未实现浮盈大的票，持有者惜售，上涨阻力小。

  F037 shadow_std（priority 2，rank 34，窗口 [20]）
